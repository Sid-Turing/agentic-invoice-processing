# Pages

Ready-made page recipes composed from templates, atoms, and molecules.

See also: [recipes/pages.md](recipes/pages.md) for App Shell and authentication page usage recipes.

### ForgotPasswordPage
Configurable password recovery page with email field, submit action, and back-to-login action

### LoginPage
Configurable authentication page with SSO actions, email/password fields, remember-me checkbox, forgot-password action, and register footer

### RegisterPage
Configurable account registration page with SSO actions, name/email/password fields, terms checkbox, and login footer

### ResetPasswordPage
Configurable password reset page with password confirmation fields and back-to-login action

### TwoFactorAuthenticationPage
Configurable two-factor authentication page with OTP slots, recovery action, resend action, and submit state

### VerifyEmailPage
Configurable email verification page with sent-to copy, skip action, and resend action
